# CCNA Daily Training & Test Log

Welcome to my daily progress repository. This space is dedicated to tracking my daily class notes and test files for the SNCNA (Suren Network Certified Network Associate) training program[cite: 1]. 

The training and daily tests are conducted by SUREN NETWORK[cite: 1].

## 📂 Repository Contents

Below is the log of daily test files uploaded to this repository:

### Day 1: Number System
* **File:** `Day_1-Number System.pdf`[cite: 2]
* **Topics Covered:** 
  * Decimal to Binary Conversion[cite: 2]
  * Hexa to Binary Conversion[cite: 2]

### Day 2: Physical Network Connection
* **File:** `Day-2-How to form a physical network connect.pdf`[cite: 1]
* **Topics Covered:** 
  * The three types of networking mediums: Radio frequency (wireless), Electrical signal (copper cable), and Light signal (fiber optic cable)[cite: 1]
  * Switch 8-pins and connecting UTP cables between two devices[cite: 1]
  * Explanations of AUTO MDIX, POE Injectors, and POE switches[cite: 1]
  * Network Interface Card (NIC) types and functions, including how it converts binary signals to electrical or radio frequency signals and vice versa[cite: 1]

### Day 3: 5-Bit Binary Combination

* **File:** `Day-3-  5bit Binary combination.pdf`
* **Topics Covered:**
* 5-bit binary combinations
* Sequential binary counting using the place values 16, 8, 4, 2, and 1

### Day 4: IP Parameters

* **File:** `Day-4-IP Parameters.pdf`
* **Topics Covered:**
* Calculating IP parameters for various given IP addresses
* Finding the Network ID, First IP, Last IP, Broadcast IP, Prefix length, and Subnetmask

### Day 5: Packet Flow

* **File:** `Packet Flow test.pdf`
* **Topics Covered:**
* CCNA Packet Flow fundamentals
* Documenting a packet flow between two devices (e.g., from IP `150.0.0.10` to `150.0.0.20`)
* Mapping out ARP Requests (ARP REQ) and ARP Replies (ARP REP), including Sender and Target IPs and MAC addresses
* Tracking ECHO requests and replies using Source/Destination IPs (SIP/DIP) and MAC addresses (SMAC/DMAC)

### Day 6: LAN Communication
 * **File:** Day 6- LAN COMMUNICATION TEST.pdf
 * **Topics Covered:**
   * **ping Command:** Using ping <IP> to send echo data and verify connectivity without data loss.
   * **NetBIOS Protocol:** Resolving computer names to target IP addresses for local network communication.
   * **SMB Protocol:** Understanding Server Message Block (SMB) for sharing files, printers, and resources across a network.
   * **Ping Process Verification:** Step-by-step verification using ipconfig to inspect IP settings followed by cross-testing communication between end hosts.
     
### Day 7: Network Devices
 * **File:** Day 7- Network Devices test.pdf
 * **Topics Covered:**
   * **Hub Behavior:** Functionality as a Layer 1 broadcasting device and associated packet loss issues.
   * **Switch Behavior:** Address learning, MAC address table maintenance (port mapping), and switching between unicast and broadcast traffic.
   * **Router Behavior:** Breaking broadcast domains, routing table structure (Network ID, Prefix, Interface), and industry-standard IP configuration practices.
